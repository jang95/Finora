# Finora

가족·지인용 개인 금융관리 웹 서비스 (가계부 / 자산 / 투자).

- 계획·진행 현황: [docs/development-plan.md](docs/development-plan.md)

## 구조

| 폴더 | 내용 |
|---|---|
| `frontend/` | React + TypeScript + Vite |
| `backend/` | ASP.NET Core Web API (Phase 3에서 생성) |
| `docs/` | 설계·계획 문서 |

## 실행

```bash
cd frontend
npm install
npm run dev
```
